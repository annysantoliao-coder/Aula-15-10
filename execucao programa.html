Execução do programa

Refere-se ao momento em que o código hospedado no servidor é processado para atender a uma requisição, gerenciar dados ou executar tarefas automatizadas.

O fluxo de execução de uma requisição

      1. Roteamento: O servidor recebe a requisição e direciona para a função correta do código.
      2. Interceptadores: Antes de processar a lógica principal, o programa executa checagens de segurança (verificar se o usuário está logado, validar dados enviados, etc.).
      3. Controladores e lógica de negócio: O núcleo do programa é executado. É aqui que os cálculos são feitos, decisões são tomadas e as regras do sistema são aplicadas.
      4. Persistência (banco de dados): O programa se comunica com o banco de dados para buscar, salvar ou atualizar informações.
      5. Resposta: O back-end finaliza a execução gerando uma resposta e a envia de volta para o cliente.
