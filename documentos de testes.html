Documentos de testes

      1. Plano de teste: serve para validar a lógica de negócios, a integridade do banco de dados, as APIs e a segurança do lado do servidor de uma aplicação.
      2. Casos de teste: verificam o funcionamento da lógica do servidor, APIs, manipulação de dados e regras de negócio.
      3. Relatório de incidentes de testes: é o documento formal que registra falhas críticas, erros de servidor, quebras de API ou instabilidade no banco de dados identificadas durante a execução dos testes.
      4. Relatório de resumo de teste: consolida os resultados dos testes executados na camada de servidor, banco de dados e APIs de um sistema.
