Elaboração do caso de teste

Conceito

É um documento estruturado que define um conjunto de condições, ações (passos), dados de entrada e resultados esperados para verificar se uma funcionalidade de um software funciona corretamente.

Estrutura básica de um caso de teste

  • ID do caso de teste: identificador único.
  • Título/Descrição: resumo do que está sendo testado.
  • Pré-condições: o que precisa existir ou estar configurado antes de começar.
  • Passos de execução: ações sequenciais que o testador deve realizar.
  • Resultado esperado: o comportamento correto que o sistema deve apresentar.

Exemplos práticos

Exemplo 1: Cenário de sucesso

  • ID: CT01
  • Título: Login de usuário com credenciais válidas
  • Pré-condições: O usuário já possui uma conta cadastrada no sistema.
  • Passos:
      • 1. Acessar a página de login.
      2. Inserir um e-mail válido no campo "E-mail".
      3. Inserir a senha correta no campo "Senha".
      4. Clicar no botão "Entrar".
  • Resultado esperado: O sistema autentica o usuário e redireciona para a página principal com a mensagem de boas-vindas.

Exemplo 2: Cenário de erro

  • ID: CT02
  • Título: Tentativa de login com senha incorreta.
  • Pré-condições: O usuário já possui uma conta cadastrada no sistema.
  • Passos:
      • 1. Acessar a página de login.
      2. Inserir um e-mail válido no campo "E-mail".
      3. Inserir a senha correta no campo "Senha".
      4. Clicar no botão "Entrar".
  • Resultado esperado: O sistema impede o acesso e exibe a mensagem de erro: "E-mail ou senha inválidos".
